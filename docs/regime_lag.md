# R2 — how late the live labeller confirms a change

k = 4. Hindsight = one mixture on the whole panel (canonical order); live = the expanding refit, confirmed. Labels agree on **60%** of labelled sessions.

11 hindsight changes (median run 3 sessions); 41 live changes. Sessions from a hindsight change to the live labeller's matching change (−10 … +120 window): **median 6**, 75th percentile 10; 64% of hindsight changes never matched inside the window.

Reading: the lag is the time the product spends labelling the previous season after the new one has begun; a negative median would mean the live label leads hindsight, which cannot happen systematically.
